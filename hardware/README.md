# Hardware

- [Wiring and electronics](../firmware/README.md): ESP32-S3, display, touch pad,
  buzzer, and volume control.
- [Case](case/README.md): parametric Fusion 360 enclosure, assembly instructions,
  geometry checks, and preview images.
- [Display reference](reference/display.step): source geometry used to size the
  case. Check dimensions against your actual display before printing.

The case model currently specifies an EC11 encoder mount; the firmware uses a
10 kΩ potentiometer for volume. Check the shaft and mounting fit for your chosen
potentiometer before printing the enclosure.
